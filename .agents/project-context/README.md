# Mémoire de Projet — Blind-War (`.agents/project-context/`)

Ce dossier conserve la mémoire structurée du projet **Blind-War** pour `prompt-engineer`, `game-director` et les agents spécialisés.

## Fichiers

- `features.md` : inventaire vérifié des fonctionnalités existantes, demandées, en cours, terminées et abandonnées.
- `decisions-and-rules.md` : règles métier officielles, invariants de sécurité anti-fuite, contraintes techniques et décisions validées.
- `changelog-and-issues.md` : historique des évolutions vérifiées, points d'attention documentaires/techniques connus et propositions facultatives en attente.

## Règle de mise à jour

- Consulter ce dossier avant toute modification importante sur `Blind-War`.
- Ne jamais déplacer une proposition dans `decisions-and-rules.md` (section Décisions validées) sans accord explicite de l'utilisateur.
